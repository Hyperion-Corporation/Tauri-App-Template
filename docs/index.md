# Tauri-App-Template Documentation

Welcome to the documentation portal for **Tauri-App-Template**. This repository provides a template for Tauri-based desktop applications featuring a high-performance C++ native backend, Python middleware (integrating C++ modules with frontend and hosting PyTorch / TensorFlow Deep Learning models), and a modern TypeScript frontend with Tauri desktop runtime integration.

## Where to Start

- [Architecture](ARCHITECTURE.md) — System design and module boundaries (backend, middleware, frontend)
- [Development](DEVELOPMENT.md) — Local setup, build prerequisites, and workflow
- [Testing](TESTING.md) — How to run unit, integration, and benchmark tests
- [Dependencies](DEPENDENCIES.md) — Third-party library policies and dependency management
